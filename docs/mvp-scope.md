# MVP scope

The current foundation includes household authentication, account-linked and managed Member profiles, profile/general invitations, reviewed join requests, leadership confirmation, typed and ordered Rooms, optional Pets, persistent member-owned cat avatars, setup completion, the household-first Dashboard shell, My Cradle (`/me`), task suggestions, guided household routine recommendations, universal Member delegation, rotation-first responsibility choices, custom routines, a friendly Routines home, and a first-party Household Schedule.

Room and Pet recommendations come from one versioned static catalog. Applying household choices creates active internal Systems with deterministic ordered steps, Room/Pet context, a canonical assignment mode and participant pool, template provenance, and plain frequency intent. Due Routines materialise dated household missions.

Schedule MVP stores household/leadership events, linked Members, recurrence intent and reminder lead time. It supports meetings, appointments, school events, trips, birthdays, reminders, Weekly Review and safe cancellation. It does not create tasks.

Deferred: recurrence-instance expansion, reminder delivery/notifications, task and execution instances, actual rotation execution, task help/request assignment, task-linked messaging, pet-care execution, inventory automation, actionable Today’s Mission, external calendar integrations, external invite delivery, recovery, passkeys, and production-distributed abuse controls.

Every implemented or deferred surface follows the permanent no-dead-end policy in `navigation-and-no-dead-ends.md`.
