# MVP scope

The current foundation includes household authentication, membership, leadership confirmation, typed and ordered Rooms, optional Pets, layered Companion creation, setup completion, the Dashboard shell, guided household routine recommendations, simple responsibility/frequency choices, custom routines, and a friendly routine library.

Room and Pet recommendations come from one versioned static catalog. Applying household choices creates active internal Systems with deterministic ordered steps, Room/Pet context, a responsible Member, optional future-rotation participants, template provenance, and plain frequency intent.

Deferred: recurrence expansion, schedules, task and execution instances, actual delegation/rotation, pet-care execution, inventory automation, Companion reactions and animation, actionable Today’s Mission, Weekly Review, real Plan/Calendar/Messages modules, recovery, passkeys, and production-distributed abuse controls.
