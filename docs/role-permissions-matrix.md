# Role permissions matrix

| Capability | Owner | Parent/Admin | Adult | Child |
| --- | --- | --- | --- | --- |
| Complete incomplete initial setup | Yes | No | No | No |
| Confirm leadership/member review | Yes | No | No | No |
| Manage Rooms during setup | Yes | No | No | No |
| Manage optional Pets during setup | Yes | No | No | No |
| Configure Companion during setup | Yes | No | No | No |
| View household members | Yes | Yes | Yes | Own safe row |
| Create member invitations | Yes | Yes | No | No |
| Manage Rooms after setup | Yes | Yes | No | No |
| Manage Pets after setup | Yes | Yes | No | No |
| Configure Companion after setup | Yes | Yes | No | No |
| Open Dashboard household summary | Yes | Yes | Yes | Yes |
| Review/apply routine recommendations | Yes | Yes | No | No |
| View active household routines | Yes | Yes | Yes | No |
| View paused/archived routine definitions | Yes | Yes | No | No |
| Edit/pause/archive routines | Yes | Yes | No | No |
| Choose responsibility/future rotation | Yes | Yes | No | No |
| View own session / sign out | Yes | Yes | Yes | Yes |

Pets and the Companion never receive permissions, credentials, roles, or sessions. Server authorization derives the role and household from the session. A Parent/Admin retains invitation permissions while waiting for the Owner to finish setup.

Routine management begins only after setup is complete. An active Owner, Parent/Admin, or Adult may be the responsible person; choosing responsibility does not grant management permission. Children are conservatively excluded from responsibility until an age/appropriateness policy exists.
